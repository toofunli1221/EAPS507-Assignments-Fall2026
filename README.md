# Assignments for EAPS 507 – Fall 2026

## About This Repository

This repository contains my Python assignments for EAPS 507 during Fall 2026 at Purdue University.

The purpose of this repository is to organize my coursework, practice version control with GitHub, and improve scientific reproducibility through clear documentation and code management.

## Assignment List

### 1. Madhava Pi Assignment

**File:** `Madhava_Pi_Assignment1.ipynb`

This assignment focuses on using Python programming to approximate the value of pi using a mathematical series. It provides practice with loops, calculations, and numerical methods.

### 2. Pandas Data Manipulation

**File:** `EAPS507_Pandas_Data_Manipulation_InClass_Tutorial.ipynb`

This assignment introduces the Pandas library for working with tabular data. It covers reading datasets, manipulating DataFrames, selecting and filtering data, and performing basic data analysis.

### 3. Xarray Beginner Tutorial

**File:** `Xarray_10_Minute_Beginner_Tutorial.ipynb`

This assignment introduces Xarray for working with multidimensional scientific datasets. It covers DataArrays, Datasets, dimensions, coordinates, and basic data selection and manipulation.

## How to Run the Notebooks

1. Download or clone this repository.
2. Open the `.ipynb` files using Jupyter Notebook or JupyterLab.
3. Install the necessary Python libraries, including NumPy, Pandas, and Xarray, as needed.
4. Run the notebook cells in order to reproduce the calculations and analysis.

Some assignments may require additional datasets provided through the course.

## Scientific Reproducibility

GitHub helps me organize my Python notebooks and track changes to my code over time. By using descriptive commit messages and documenting each assignment, I can understand how my work has developed and make it easier for others to review and reproduce my analysis.
